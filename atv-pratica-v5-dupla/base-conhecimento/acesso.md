# Recuperação de acesso

O usuário deve utilizar a opção “Esqueci minha senha” na tela de login.

O código de recuperação possui validade limitada. Senhas e códigos de
autenticação nunca devem ser enviados em chamados.

Quando o e-mail não chegar, o usuário deve confirmar apenas o endereço
parcialmente mascarado exibido pelo sistema.
